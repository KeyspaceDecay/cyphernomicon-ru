## О проекте

«Сайферномикон» (в этом переводе — «Шифромикон») — фундаментальный текст
культуры шифропанков: смесь хакерского андеграунда, радикального
либертарианства, криптоанархизма и академической точности 1990-х. FAQ о
криптографии, анонимности, ремейлерах, цифровых наличных, Clipper, слежке,
репутациях и криптоанархии — более 22 000 строк.

## Принципы перевода

- Терминология: cypherpunk → **шифропанк**, crypto anarchy → **криптоанархия**,
  remailer → **ремейлер**, blinding → **блайндинг**, true name → **истинное имя**,
  one-time pad → **одноразовый блокнот**, traffic analysis → **анализ трафика**;
  to detweiler → **детвейлерить**.
- Названия организаций и законов оставлены на английском с переводом в скобках
  при первом упоминании (NSA, EFF, IRS, ITAR, Clipper).
- Сохранены структура оригинала (тезисные списки `-`/`+`, нумерация секций),
  атрибуции цитат, URL, адреса, PGP-блоки и email-заголовки (как артефакты эпохи).
